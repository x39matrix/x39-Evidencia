# Seguridad / Security

Si encuentras un fallo de seguridad en X-39 Evidencia, escribe a security@x39matrix.org antes de hacerlo público. La política canónica es el `security.txt` de la web: <https://x39matrix.org/.well-known/security.txt>.
Alcance: el verificador de referencia (`verify_bundle.py`), la web (x39matrix.org) y la API (api.x39matrix.org). Es un proyecto de código abierto (AGPL-3.0) mantenido por una sola persona: se agradece el aviso y se responde lo antes posible. Idiomas: es, en.

---

If you find a security issue in X-39 Evidencia, write to security@x39matrix.org before making it public. The canonical policy is the website's `security.txt`: <https://x39matrix.org/.well-known/security.txt>.
Scope: the reference verifier (`verify_bundle.py`), the website (x39matrix.org) and the API (api.x39matrix.org). This is an open-source project (AGPL-3.0) maintained by one person: reports are welcome and answered as soon as possible. Languages: es, en.
